Um PDF muito grande causa problemas em todo o lado: anexos de e-mail rejeitados, formulários com limites de tamanho e partilha via WhatsApp a comprimir o documento. Este guia explica como reduzir o tamanho de um PDF grátis sem perder legibilidade.

## Porque é que o meu PDF é tão grande?

Entender o motivo ajuda a escolher a solução certa. As três causas mais comuns:

**Imagens em alta resolução dentro do PDF**
Ao criar um PDF a partir do Word, PowerPoint ou de um scan, as imagens costumam ficar em resolução total (300 ppp ou mais). Um documento com 10 fotos em alta resolução pode passar facilmente dos 20 MB. Comprimir essas imagens é a forma mais eficaz de reduzir o tamanho.

**Documentos digitalizados guardados como imagens**
Se digitalizou um documento em papel e guardou como PDF, cada página é uma foto em resolução total. Esses PDF podem ser enormes — por vezes 5–10 MB por página. A compressão reduz a qualidade da imagem para um nível mais adequado à web.

**Fontes e recursos incorporados**
Os PDF incorporam cópias das fontes para aparecerem correctamente em qualquer dispositivo. Conjuntos de fontes muito grandes ou incomuns aumentam o tamanho. É em geral um factor menor mas a ter em conta.

### Passo 2: Enviar o PDF

## Reduzir o tamanho do PDF em diferentes dispositivos

### No Windows
A forma gratuita mais fácil é o FileFlip: abra o Chrome ou Edge, vá a fileflip.org/tools/compress-pdf, envie e transfira. Sem instalação.

Para uso offline, o Adobe Acrobat (pago) e o LibreOffice (grátis) também podem reduzir o PDF; no LibreOffice: abrir o PDF, Ficheiro → Exportar como PDF e baixar a qualidade de imagem.

### No Mac
No Mac, a app Pré-visualização permite comprimir: abra o PDF na Pré-visualização → Ficheiro → Exportar como PDF → menu Filtro Quartz → Reduzir tamanho do ficheiro. A compressão da Pré-visualização pode ser agressiva; o FileFlip dá mais controlo sobre a qualidade.

### No iPhone e Android
Abra [fileflip.org/tools/compress-pdf](/pt/tools/compress-pdf) no browser do telemóvel. Envie a partir de Ficheiros (iOS) ou do gestor de ficheiros (Android) e transfira o PDF comprimido para o dispositivo.

### Sem Adobe Acrobat
O Adobe Acrobat é o padrão mas custa mais de 20 €/mês. O FileFlip oferece o mesmo resultado grátis, sem subscrição.

## Outras formas de reduzir o tamanho do PDF

Se só comprimir não chega:

**Dividir o PDF e comprimir cada parte**
Use [Dividir PDF](/pt/tools/split-pdf) para partir o documento, comprima cada parte e depois [Unir PDF](/pt/tools/merge-pdf) para juntar. Por vezes o resultado é melhor do que comprimir o ficheiro inteiro de uma vez.

**Extrair só as páginas necessárias**
Se só precisa de partilhar certas páginas, use [Extrair páginas PDF](/pt/tools/extract-pdf-pages) para ficar apenas com essas. Partilhar 3 páginas em vez de 30 é a maior redução possível.

**Converter para PDF/A para arquivo**
Para arquivar a longo prazo com compatibilidade garantida, use [PDF para PDF/A](/pt/tools/pdf-to-pdfa) para o formato de arquivo ISO.

## Perguntas frequentes

**Comprimir um PDF reduz a qualidade do texto?**
Não. A compressão do FileFlip optimiza as imagens incorporadas mas não altera o texto. O texto continua nítido, pesquisável e copiável.

**É seguro comprimir PDF confidenciais online?**
Com o FileFlip sim. A compressão é feita no browser. O PDF não é enviado para nenhum servidor — adequado para contratos, registos médicos ou extratos.

**O meu PDF continua demasiado grande. O que fazer?**
Experimente [Dividir PDF](/pt/tools/split-pdf) para extrair só as páginas que precisa. Se o PDF tiver muitas imagens em alta resolução, a compressão já fez o máximo; nesse caso seria preciso reexportar as imagens originais em menor resolução antes de criar o PDF.

**Posso comprimir um PDF protegido por palavra-passe?**
Primeiro remova a palavra-passe com [Desbloquear PDF](/pt/tools/pdf-unlock), comprima o ficheiro desbloqueado e, se quiser, volte a proteger com [Proteger PDF](/pt/tools/protect-pdf).

**Reduzir o tamanho invalida assinaturas digitais?**
Sim. A compressão altera o conteúdo e normalmente invalida assinaturas digitais. Se o PDF tiver assinaturas com valor legal, guarde o original assinado e partilhe apenas uma cópia comprimida para referência.

**Como reduzir um PDF criado a partir de um scan?**
PDF digitalizados (cada página = uma foto) comprimem muito bem. Envie para o FileFlip: a compressão reduz o ppp das imagens a níveis adequados à web, com reduções típicas de 50–70 %.
