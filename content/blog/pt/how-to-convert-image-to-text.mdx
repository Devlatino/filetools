# Como Converter Imagem em Texto Grátis — OCR Online

Quando tem uma foto de um documento, uma captura de ecrã de um artigo ou uma página digitalizada, não pode copiar nem editar o texto — está dentro da imagem. O OCR (Reconhecimento Óptico de Caracteres) lê o texto na imagem e converte-o em texto editável e copiável. Este guia explica como fazer grátis.

## O que é o OCR e como funciona?

OCR significa Reconhecimento Óptico de Caracteres. É a tecnologia que lê o texto dentro das imagens analisando a forma das letras e palavras. O OCR moderno usa aprendizagem automática para reconhecer texto em diferentes fontes, tamanhos e idiomas, mesmo em fotos tiradas em ângulo ou com pouca luz.

O OCR converte: **documentos digitalizados** → texto editável; **capturas de ecrã** → texto copiável; **fotos de placas ou livros** → texto pesquisável; **cartões de visita** → dados de contacto; **recibos e faturas** → dados para colar numa folha de cálculo.

## Dicas para melhores resultados OCR

**Alta resolução** — Abaixo de 150 DPI os resultados costumam ser fracos. Digitalize a 300 DPI ou mais. Se fotografar com o telemóvel, mantenha a imagem nítida e focada.

**Bom contraste** — Texto escuro em fundo claro funciona melhor. Evite imagens onde a cor do texto seja semelhante ao fundo.

**Imagem plana e direita** — Texto numa página curva (livro aberto) ou em ângulo é mais difícil de ler. Aplane a página e fotografe de cima.

**Evite sombras e reflexos** — Reduzem bastante a precisão. Use luz natural ou uma lâmpada para documentos.

**PNG em vez de JPG para capturas** — Capturas em PNG são mais nítidas (sem perda). Carregue capturas em PNG para extração mais precisa.

## Usos comuns

**Digitalizar documentos em papel** — Digitalize documentos antigos e use OCR para tornar o texto pesquisável e editável. Ideal para arquivar contratos, cartas, faturas e registos.

**Copiar texto de capturas** — Quando não consegue copiar de um PDF, site ou vídeo, faça uma captura e passe-a pelo OCR.

**Ler texto de fotos** — Extrair texto de uma foto de placa, quadro, livro ou nota manuscrita.

**Extrair dados de recibos** — Passe recibos e faturas pelo OCR para extrair valores, datas e descrições.

**Tornar PDFs digitalizados pesquisáveis** — Um PDF digitalizado são apenas imagens. Converta as páginas em imagens com [PDF para JPG](/pt/tools/pdf-to-jpg) e use Imagem para Texto em cada uma.

## Imagem para Texto vs PDF para Texto

- **Imagem para Texto** — extrai texto de JPG, PNG e outras imagens com OCR.
- **PDF para Texto** — extrai texto de um PDF que já tem texto selecionável (não um PDF digitalizado).

Para PDFs digitalizados: converta primeiro em imagens com [PDF para JPG](/pt/tools/pdf-to-jpg), depois extraia o texto de cada imagem.

## Formatos suportados

O FileFlip aceita JPG/JPEG, PNG, WebP, GIF, BMP, TIFF. Para HEIC (fotos iPhone) converta primeiro em JPG com [HEIC para JPG](/pt/tools/heic-to-jpg) e depois execute o OCR.
