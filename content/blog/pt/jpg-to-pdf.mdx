# JPG para PDF — Converter Imagens em PDF Grátis Online

Converter uma imagem JPG para PDF é uma das tarefas mais comuns. Quer esteja a enviar uma foto como documento, a juntar várias imagens num ficheiro ou a facilitar a impressão de uma foto, o PDF é o formato certo. Este guia explica como converter JPG para PDF grátis, em qualquer dispositivo.

## Porquê converter JPG para PDF?

O JPG é o formato padrão das fotos em smartphones e câmaras digitais. É ótimo para partilhar imagens mas não o ideal quando precisa de:

- **Enviar uma foto como documento formal** — candidaturas, reclamações, pedidos de visto e muitos formulários oficiais exigem PDF, não JPG
- **Combinar várias fotos num único ficheiro** — em vez de enviar 10 ficheiros JPG, pode juntá-los num só PDF
- **Imprimir com dimensões exatas** — o PDF mantém dimensões e margens; o JPG pode imprimir em tamanhos diferentes consoante as definições
- **Proteger uma imagem com palavra-passe** — o PDF suporta proteção por palavra-passe, o JPG não
- **Arquivar fotos de forma profissional** — o PDF/A é o padrão internacional para arquivo a longo prazo

## Como converter JPG para PDF no Windows

### Método 1 — Microsoft Print to PDF (integrado, grátis)
1. Abra o ficheiro JPG em Fotos ou noutro visualizador de imagens
2. Prima **Ctrl+P** para abrir o diálogo de impressão
3. Selecione **Microsoft Print to PDF** como impressora
4. Clique em Imprimir e escolha onde guardar o PDF

Funciona para uma imagem de cada vez. Para várias, use o FileFlip.

### Método 2 — FileFlip (navegador, vários ficheiros, grátis)
O método mais rápido para conversão em lote. Carregue todos os JPG e transfira um único PDF.

### Método 3 — Adobe Acrobat (pago)
O Adobe Acrobat pode converter JPG para PDF com opções avançadas. Custa cerca de 19,99 €/mês. O FileFlip oferece o mesmo resultado grátis.

## Como converter JPG para PDF no Mac

### Método 1 — Pré-visualização (integrado, grátis)
1. Abra o JPG na Pré-visualização
2. Vá a **Ficheiro → Exportar como PDF**
3. Escolha o nome e a pasta

Para várias imagens: selecione todos os JPG no Finder, clique com o botão direito e **Abrir com → Pré-visualização**. Depois Ficheiro → Imprimir → Guardar como PDF.
