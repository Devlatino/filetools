Ein PDF zu teilen ermöglicht, aus einer großen Datei mehrere kleine zu machen – nach Kapitel, Abschnitt oder in Einzelseiten. Sie möchten vielleicht nur einen Teil per E-Mail schicken, die Dateigröße verkleinern, indem Sie nur die nötigen Seiten behalten, oder bestimmte Seiten in einem anderen Projekt nutzen. Sie können ein PDF kostenlos online im Browser teilen, ohne Software zu installieren. Dieser Guide erklärt den Unterschied zwischen Teilen nach Seitenbereich und Extrahieren einzelner Seiten, die Schritt-für-Schritt-Nutzung von FileFlip, wie Teilen die Dateigröße reduziert und die Nutzung auf dem Handy.

## Nach Seitenbereich teilen vs. einzelne Seiten extrahieren

- **Nach Seitenbereich teilen** — Sie legen Bereiche fest (z. B. Seiten 1–5, 6–10, 11–15) und erhalten ein PDF pro Bereich. Ideal, um ein Dokument in logische Blöcke (Kapitel, Abschnitte) zu unterteilen. Die ursprüngliche Reihenfolge bleibt in jeder neuen Datei erhalten.
- **Einzelne Seiten extrahieren** — Sie wählen einzelne Seiten (z. B. 3, 7, 12) und erhalten ein PDF pro Seite oder ein PDF nur mit diesen Seiten. Nützlich, wenn Sie bestimmte Seiten (Formular, Diagramm) ohne den Rest brauchen.

Manche Tools bieten beides. Wählen Sie je nach gewünschter Nutzung des Inhalts.

## Schritt für Schritt mit FileFlip

1. Öffnen Sie das Tool [PDF teilen](/de/tools/split-pdf).
2. Laden Sie Ihr PDF hoch (Klick oder Drag & Drop). Das Tool zeigt die Seitenzahl an.
3. Wählen Sie die Teilung: nach Seitenbereich (z. B. 1–5, 6–10) oder Extraktion bestimmter Seiten, je nach Tool.
4. Teilung ausführen. Sie erhalten ein oder mehrere PDFs zum Download – als ZIP oder einzeln.
5. Ergebnis herunterladen. Kein Konto nötig.

Das Tool funktioniert in Desktop- und Mobilbrowsern. Die Verarbeitung kann lokal laufen, sodass die Datei nicht auf einen Server hochgeladen wird; Details auf der Tool-Seite.

## Großes PDF teilen, um die Dateigröße zu reduzieren

Ist ein PDF zu groß für E-Mail oder Upload, hilft Teilen: Behalten Sie nur die benötigten Seiten. Z. B. ein 50-seitiger Bericht – teilen und nur die „Zusammenfassung“ (Seiten 1–3) herunterladen. Sie können die Teile danach auch [komprimieren](/de/tools/compress-pdf), wenn Sie noch kleinere Dateien brauchen. Teilen komprimiert den Inhalt nicht – es reduziert nur die Seitenzahl pro Datei. Für maximale Verkleinerung zuerst teilen, dann die behaltenen Teile komprimieren.

## PDF auf dem Handy teilen

Sie können ein PDF auf dem Handy oder Tablet ohne App teilen. Öffnen Sie die FileFlip-Seite [PDF teilen](/de/tools/split-pdf) in Safari (iPhone/iPad) oder Chrome (Android), dann:

1. Tippen Sie zum Hochladen des PDF vom Gerät oder aus der Cloud (z. B. iCloud, Google Drive).
2. Wählen Sie die Teilungsoption (Bereiche oder Einzelseiten).
3. Teilung ausführen und die neuen PDFs herunterladen oder teilen.

Die Verarbeitung läuft im Browser. Bei sehr großen PDFs hilft eine stabile Verbindung. Bei sehr großer Datei oder vielen Bereichen kann das Teilen am Computer schneller sein.

## FAQ

**Ist das Teilen von PDFs kostenlos?**  
Ja. Das Tool PDF teilen von FileFlip ist kostenlos; kein Konto oder Abo. Es kann Limits bei Dateigröße oder Seitenzahl pro Durchlauf geben.

**Kann ich teilen und den Rest des PDF behalten?**  
Teilen erzeugt neue Dateien aus den gewählten Seiten; das Original wird nicht gelöscht. Bewahren Sie das Original-PDF auf, falls Sie das vollständige Dokument später brauchen.

**Was, wenn ich die Seiten nach dem Teilen neu ordnen muss?** — Sie können die entstandenen PDFs in anderer Reihenfolge mit einem Tool [PDF zusammenführen](/de/tools/merge-pdf) zusammenführen oder [Seiten extrahieren/reorden](/de/tools/extract-pdf-pages) nutzen, wenn Sie vor dem Teilen umordnen müssen.

**Werden meine Dateien auf einen Server hochgeladen?**  
Läuft das Tool lokal, wird Ihr PDF auf Ihrem Gerät verarbeitet und nicht an einen Server gesendet. Siehe Tool-Seite für das aktuelle Verhalten.
