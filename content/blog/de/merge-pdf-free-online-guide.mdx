Mehrere PDFs in einer Datei zu vereinen, ist ein häufiger Bedarf: Berichte, Verträge, gescannte Seiten oder Kapitel in einem einzigen Dokument. Dafür brauchen Sie keine Desktop-Software oder kostenpflichtiges Abo – Sie können PDF-Dateien kostenlos online im Browser zusammenführen. Dieser Guide erklärt, wie Sie mit FileFlip PDFs zusammenführen, wie Sie Seiten vor dem Zusammenführen sortieren, wie es auf iPhone und Android funktioniert und was der Unterschied zwischen „Zusammenführen“ und „Seiten kombinieren“ ist.

## Schritt für Schritt mit FileFlip

Das Zusammenführen von PDFs mit FileFlip ist unkompliziert und läuft im Browser. Die Dateien können lokal verarbeitet werden, sodass kein Upload auf einen Server nötig ist.

1. Öffnen Sie das Tool [PDF zusammenführen](/de/tools/merge-pdf).
2. Klicken Sie auf den Upload-Bereich oder ziehen Sie Ihre PDF-Dateien per Drag & Drop. Sie können mehrere Dateien hinzufügen; sie erscheinen in einer Liste in der Reihenfolge der Eingabe.
3. Sortieren Sie die Dateien oder die Seiten darin bei Bedarf (siehe nächster Abschnitt).
4. Klicken Sie auf **Zusammenführen**. Das Tool erstellt ein einziges PDF.
5. Laden Sie das zusammengeführte PDF herunter.

Kein Konto nötig. Das Tool funktioniert in Desktop- und Mobilbrowsern. Bei sehr großen oder vielen Dateien kann die Verarbeitung etwas länger dauern.

## Seiten vor dem Zusammenführen sortieren

Die Reihenfolge, in der Sie Dateien hinzufügen, ist die Reihenfolge im zusammengeführten PDF. Wenn Sie eine andere Reihenfolge brauchen:

- **Ganze Dateien sortieren** — Ziehen Sie in der Dateiliste Dateien nach oben oder unten, sodass die gewünschte erste Datei oben steht, dann die zweite usw. Die Seiten jeder Datei bleiben in dieser Reihenfolge zusammen.
- **Seiten innerhalb einer Datei sortieren** — Manche Merge-Tools erlauben, eine Datei zu öffnen und einzelne Seiten zu verschieben. Wenn nicht, führen Sie in der bestmöglichen Reihenfolge zusammen und nutzen Sie danach ein Tool [PDF teilen](/de/tools/split-pdf) oder zum Sortieren, um das Ergebnis zu teilen und erneut zusammenzuführen, oder ein Tool [PDF-Seiten sortieren](/de/tools/reorder-pdf-pages), falls vorhanden.

Die Reihenfolge vor dem Zusammenführen zu planen spart Zeit und vermeidet Doppelarbeit.

## PDF auf iPhone und Android zusammenführen

Sie können PDFs auf dem Handy oder Tablet zusammenführen, ohne eine App zu installieren. Öffnen Sie die FileFlip-Seite [PDF zusammenführen](/de/tools/merge-pdf) in Safari (iPhone/iPad) oder Chrome (Android), dann:

1. Tippen Sie auf **Hochladen** oder **Dateien hinzufügen** und wählen Sie PDFs vom Gerät oder aus der Cloud (z. B. iCloud, Google Drive).
2. Sortieren Sie die Dateien per Drag & Drop, falls die Oberfläche es erlaubt.
3. Tippen Sie auf **Zusammenführen** und warten Sie auf das Ergebnis.
4. Laden Sie das zusammengeführte PDF herunter oder teilen Sie es.

Die Verarbeitung läuft im Browser; bei großen Dateien hilft eine stabile Verbindung. Bei vielen oder sehr großen PDFs kann das Zusammenführen am Computer schneller sein.

## PDF zusammenführen vs. Seiten kombinieren

Oft werden „PDF zusammenführen“ und „PDF-Seiten kombinieren“ gleich verwendet: mehrere PDFs oder Seiten in einer Datei. In der Praxis:

- **PDF zusammenführen** — Bedeutet meist, mehrere PDF-*Dateien* zu nehmen und ein PDF zu erzeugen, das alle ihre Seiten in gewählter Reihenfolge enthält. Das macht z. B. das Merge-Tool von FileFlip.
- **Seiten kombinieren** — Kann dasselbe sein wie zusammenführen oder das Einfügen bestimmter Seiten aus verschiedenen Dokumenten in eines. Das Ergebnis ist ebenfalls ein PDF.

Im Alltag sind „zusammenführen“ und „kombinieren“ also oft dasselbe. Wichtig ist, mehrere PDFs hinzuzufügen, die Reihenfolge zu setzen und eine einzige Ausgabedatei zu bekommen – genau das bietet das FileFlip-Tool PDF zusammenführen.

## FAQ

**Ist das Zusammenführen von PDFs kostenlos?**  
Ja. Das Tool PDF zusammenführen von FileFlip ist kostenlos; kein Konto oder Abo nötig. Es kann Limits bei Dateigröße oder Anzahl der Dateien pro Durchlauf geben.

**Ändert sich die Qualität meiner PDFs?**  
Beim Zusammenführen bleibt der Inhalt in der Regel unverändert (gleicher Text, Bilder und Auflösung). Das Tool kombiniert die Seiten ohne Neuencodierung, sofern nicht anders angegeben.

**Kann ich mehr als zwei PDFs zusammenführen?**  
Ja. Sie können so viele PDFs hinzufügen, wie das Tool erlaubt, und alle auf einmal zusammenführen. Prüfen Sie die Tool-Limits (max. Anzahl Dateien oder Gesamtgröße).

**Werden meine Dateien auf einen Server hochgeladen?**  
Wenn das Tool lokal läuft, werden Ihre PDFs auf Ihrem Gerät verarbeitet und nicht an einen Server gesendet. Details stehen auf der Tool-Seite.

**Was, wenn ich später Seiten entfernen oder hinzufügen muss?**  
Sie können das zusammengeführte PDF mit einem Tool [PDF teilen](/de/tools/split-pdf) teilen oder erneut mit weiteren PDFs zusammenführen. Um die Dateigröße nach dem Zusammenführen zu verkleinern, nutzen Sie [PDF komprimieren](/de/tools/compress-pdf).
