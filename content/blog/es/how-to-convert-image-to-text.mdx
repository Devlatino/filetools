# Cómo Convertir Imagen a Texto Gratis — OCR Online

Cuando tienes una foto de un documento, una captura de un artículo o una página escaneada, no puedes copiar ni editar el texto: está dentro de la imagen. El OCR (Reconocimiento Óptico de Caracteres) lee el texto en la imagen y lo convierte en texto editable y copiable. Esta guía explica cómo hacerlo gratis.

## ¿Qué es el OCR y cómo funciona?

OCR significa Reconocimiento Óptico de Caracteres. Es la tecnología que lee el texto dentro de las imágenes analizando la forma de letras y palabras. El OCR moderno usa aprendizaje automático para reconocer texto en distintas fuentes, tamaños e idiomas, incluso en fotos tomadas en ángulo o con poca luz.

El OCR convierte:
- **Documentos escaneados** → texto editable
- **Capturas de pantalla** → texto copiable
- **Fotos de carteles o libros** → texto buscable
- **Tarjetas de visita** → datos de contacto
- **Recibos y facturas** → datos para pegar en una hoja de cálculo

## Consejos para mejores resultados OCR

La precisión depende mucho de la calidad de la imagen:

**Imágenes en alta resolución** — Por debajo de 150 ppp los resultados suelen ser malos. Escanea a 300 ppp o más. Si fotografías con el móvil, que la imagen esté nítida y enfocada.

**Buen contraste** — Texto oscuro sobre fondo claro da mejor resultado. Evita imágenes donde el color del texto sea similar al fondo.

**Imagen plana y recta** — El texto en una página curva (libro abierto) o en ángulo se lee peor. Aplana la página y fotografía desde arriba.

**Evita sombras y reflejos** — Las sombras y el flash reducen mucho la precisión. Usa luz natural o una lámpara para documentos.

**PNG en lugar de JPG para capturas** — Las capturas en PNG son más nítidas porque PNG no tiene pérdida. Sube capturas en PNG para una extracción más precisa.

## Usos habituales de imagen a texto

**Digitalizar documentos en papel** — Escanea documentos antiguos y usa OCR para hacer el texto buscable y editable. Ideal para archivar contratos, cartas, facturas y registros.

**Copiar texto de capturas** — Cuando no puedes copiar de un PDF, web o subtítulo, haz una captura y pásala por OCR.

**Leer texto de fotos** — Extrae el texto de una foto de cartel, pizarra, libro o nota manuscrita. Útil para digitalizar sin reescribir.

**Extraer datos de recibos** — Pasa recibos y facturas por OCR para extraer importes, fechas y descripciones para el control de gastos.

**Hacer buscables los PDF escaneados** — Un PDF escaneado son solo imágenes. Convierte las páginas a imágenes con [PDF a JPG](/es/tools/pdf-to-jpg) y luego usa Imagen a Texto en cada una para tener texto buscable.

## Imagen a Texto vs PDF a Texto

FileFlip ofrece dos herramientas relacionadas:

- **Imagen a Texto** — extrae texto de JPG, PNG y otras imágenes con OCR
- **PDF a Texto** — extrae texto de un PDF que ya tiene texto seleccionable (no un PDF escaneado)

Para PDF escaneados sin texto seleccionable: convierte primero a imágenes con [PDF a JPG](/es/tools/pdf-to-jpg) y luego extrae el texto de cada imagen.

## Formatos de imagen admitidos para OCR

La herramienta Imagen a Texto de FileFlip acepta: JPG/JPEG, PNG, WebP, GIF, BMP, TIFF. Para HEIC (fotos de iPhone) convierte primero a JPG con [HEIC a JPG](/es/tools/heic-to-jpg) y luego ejecuta el OCR.
