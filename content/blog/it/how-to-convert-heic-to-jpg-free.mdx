Se hai mai provato a condividere una foto iPhone con qualcuno che usa Windows o Android, ti sarai imbattuto nel problema HEIC. ## Cos'è HEIC e perché l'iPhone lo usa?

HEIC sta per High Efficiency Image Container. Apple l'ha introdotto in iOS 11 come formato predefinito della fotocamera. Il motivo è semplice: i file HEIC sono circa la metà rispetto ai JPG a parità di qualità visiva. Così puoi avere più foto sul tuo iPhone senza riempire la memoria.

Il problema è la compatibilità. HEIC è un formato Apple e mentre i Mac recenti lo aprono nativamente, Windows 10 e 11 richiedono un codec a pagamento dal Microsoft Store per visualizzare i file HEIC. I telefoni Android non lo supportano affatto. La maggior parte dei social, dei moduli web e degli editor di documenti si aspetta JPG o PNG — non HEIC.

## Perché convertire HEIC in JPG

Ecco le situazioni più comuni in cui convertire HEIC in JPG è necessario:

- **Inviare foto via email o WhatsApp** a chi usa Windows o Android
- **Caricare su siti e moduli web** che accettano solo JPG o PNG
- **Modificare foto in software** come Photoshop, Lightroom o GIMP
- **Condividere foto sui social** che non accettano HEIC
- **Stampare foto** in laboratorio o servizi di stampa
- **Allegare foto a documenti** come CV o moduli di candidatura

## Come convertire HEIC in JPG su Windows 10 e 11

Se vuoi convertire file HEIC senza aprire il browser, Windows offre alcune opzioni integrate:

**Opzione 1: Usa l'app Foto (richiede codec)**
Microsoft offre il codec HEIF Image Extensions nel Microsoft Store. Una volta installato, l'app Foto può aprire e salvare i file HEIC come JPG. Tuttavia questo codec costa 0,99 € in alcune regioni.

**Opzione 2: Usa Paint**
Nelle build più recenti di Windows 11 puoi aprire i file HEIC direttamente in Paint dopo aver installato il codec, poi File → Salva con nome → JPEG.

**Opzione 3: Usa FileFlip (gratis, senza installazione)**
L'opzione più veloce a costo zero. Apri Chrome o Edge, vai su FileFlip, fatto.

## Come convertire HEIC in JPG su Mac

Su macOS i file HEIC si aprono automaticamente in Anteprima. Per convertire in JPG:

1. Apri il file HEIC in Anteprima
2. Vai su File → Esporta
3. Seleziona JPEG dal menu formato
4. Regola la qualità se serve e clicca Salva

Per convertire molti file in batch, FileFlip è più veloce — seleziona tutti i file e scarica un ZIP.
