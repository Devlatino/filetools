# Come Unire PDF Gratis — Combina File PDF Online

Unire file PDF è uno dei compiti più frequenti in ufficio o a casa. Invece di inviare cinque allegati separati, combinarli in un unico PDF professionale fa risparmiare tempo e appare più ordinato. Questa guida spiega come unire PDF gratis — online, su Windows, Mac, iPhone e Android. In Italia è utile per bandi SUAP, invii PEC, fatture verso la PA e documentazione catastale: spesso serve un unico PDF che riunisca più documenti.

## Perché unire file PDF?

- **Candidature** — unisci CV, lettera di presentazione e certificati in un solo PDF
- **Fatture e contratti** — combina più pagine in un unico documento da firmare
- **Appunti e dispense** — unisci i PDF delle lezioni in un file per materia
- **Report** — combina export, grafici e analisi in un unico documento
- **Documenti legali** — allega allegati e riferimenti al documento principale
- **Scansioni** — quando lo scanner crea un PDF per pagina, uniscili in un unico file

## Come unire PDF su Windows (gratis)

### Metodo 1 — FileFlip (browser, senza installazione)
Il metodo gratuito più veloce. Funziona in Chrome, Edge o Firefox.

### Metodo 2 — Microsoft Word
1. Apri Word e vai a Inserisci → Oggetto → Testo da file
2. Seleziona i file PDF da unire
3. Word li converte in formato modificabile — poi File → Esporta → Crea PDF

Nota: può alterare la formattazione, soprattutto in PDF complessi.

### Metodo 3 — Adobe Acrobat (a pagamento)
Acrobat ha uno strumento Combina file dedicato. Richiede abbonamento da circa 19,99 €/mese. FileFlip fa lo stesso gratis.

## Come unire PDF su Mac (gratis)

### Metodo 1 — Anteprima (integrato, gratuito)
1. Apri il primo PDF in Anteprima
2. Vai a Visualizza → Anteprime per vedere il pannello pagine
3. Trascina pagine da altri PDF nel pannello anteprime
4. Riorganizza trascinando
5. File → Esporta come PDF per salvare il documento unito

È il miglior metodo gratuito su Mac per unire pochi PDF con contenuto semplice.

### Metodo 2 — FileFlip (browser, più veloce con molti file)
Per più di 3–4 file, FileFlip è più veloce e affidabile del trascinamento in Anteprima.

## Come unire PDF su iPhone (gratis)

1. Apri Safari e vai su [fileflip.org/tools/merge-pdf](/it/tools/merge-pdf)
2. Tocca carica e seleziona i file PDF dall'app File
3. Riorganizza se serve e tocca Unisci PDF
4. Scarica il file unito direttamente su iPhone

iOS non ha una funzione nativa per unire PDF, quindi FileFlip è la soluzione gratuita più semplice.

## Unisci PDF vs Dividi PDF

- **Unisci PDF**: combina più file in uno → [Unisci PDF](/it/tools/merge-pdf)
- **Dividi PDF**: divide un PDF in file separati o estrae pagine → [Dividi PDF](/it/tools/split-pdf)
- **Comprimi PDF**: riduce la dimensione del file unito → [Comprimi PDF](/it/tools/compress-pdf)
- **Proteggi PDF**: aggiungi password al documento unito → [Proteggi PDF](/it/tools/protect-pdf)

## Consigli per unire PDF al meglio

**Controlla l'orientamento** — Se alcuni PDF sono verticali e altri orizzontali, il file unito avrà orientamenti misti. Di solito va bene, ma conviene controllare prima di inviare.

**Comprimi dopo l'unione** — I PDF uniti sono spesso più grandi del previsto. Dopo aver unito usa [Comprimi PDF](/it/tools/compress-pdf) per ridurre la dimensione per email o upload.

**Controlla l'ordine** — In FileFlip puoi trascinare i file per riordinarli. Verifica la sequenza, soprattutto per documenti in più sezioni.

**PDF protetti da password** — Se uno dei PDF sorgente è protetto, usa prima [Sblocca PDF](/it/tools/pdf-unlock), poi unisci.

## Domande frequenti

**Posso unire PDF gratis senza filigrana?**  
Sì. FileFlip unisce i PDF gratis e non aggiunge filigrane. Il risultato è pulito e professionale.

**C'è un limite al numero di file?**  
FileFlip elabora nel browser quindi non c'è limite lato server. Per batch molto grandi i tempi dipendono dalla memoria del dispositivo.

**Unire i PDF riduce la qualità?**  
No. Contenuto, immagini, font e formattazione restano a piena qualità.

**Posso unire un PDF e un Word?**  
Non direttamente. Prima converti il Word in PDF con [Word to PDF](/it/tools/word-to-pdf), poi unisci i due PDF.

**Posso unire un PDF e immagini JPG?**  
Prima converti le JPG in PDF con [JPG to PDF](/it/tools/jpg-to-pdf), poi usa Unisci PDF.

**È sicuro per PDF riservati?**  
Sì. Elaborazione locale nel browser; i file non vengono caricati su server.

**Posso riordinare le pagine dopo?**  
Puoi riordinare i file prima di unire. Per riordinare singole pagine usa [Dividi PDF](/it/tools/split-pdf) per estrarre e poi unire nell'ordine desiderato.

**Perché il PDF unito è così grande?**  
Ogni PDF sorgente contribuisce con tutto il contenuto. Se ci sono immagini ad alta risoluzione, il file sarà grande. Usa [Comprimi PDF](/it/tools/compress-pdf) dopo l'unione.
