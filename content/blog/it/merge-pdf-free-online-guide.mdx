Unire più PDF in uno è un’esigenza comune: report, contratti, pagine scansionate o capitoli che vuoi in un unico file. Non servono software da installare né abbonamenti a pagamento: puoi unire file PDF online gratis nel browser. Questa guida ti spiega come unire PDF con FileFlip, come riordinare le pagine prima di unire, come farlo su iPhone e Android e in che cosa unire differisce dal “combinare pagine”.

## Passo-passo con FileFlip

Unire PDF con FileFlip è semplice e avviene nel browser. I file possono essere elaborati in locale così non devono essere caricati su un server.

1. Apri il tool [Unisci PDF](/it/tools/merge-pdf).
2. Clicca sull’area di upload o trascina i file PDF. Puoi aggiungere più file; appariranno in una lista nell’ordine in cui li hai aggiunti.
3. Riordina i file o le pagine al loro interno se serve (vedi sezione successiva).
4. Clicca **Unisci**. Il tool combina tutto in un unico PDF.
5. Scarica il PDF unito.

Non serve un account. Il tool funziona su browser desktop e mobile. Per file molto grandi o molti documenti l’elaborazione può richiedere un po’ di tempo.

## Come riordinare le pagine prima di unire

L’ordine in cui aggiungi i file è l’ordine in cui appariranno nel PDF unito. Se ti serve un ordine diverso:

- **Riordina interi file** — Nella lista dei file, trascina i file in alto o in basso così il primo file che vuoi è in cima, poi il secondo e così via. Le pagine di ogni file restano insieme in quell’ordine.
- **Riordina le pagine dentro un file** — Alcuni tool di merge permettono di espandere un file e trascinare le singole pagine. Se il tuo tool non lo fa, unisci nel miglior ordine possibile e poi usa un tool [Dividi PDF](/it/tools/split-pdf) o di riordino per dividere il risultato e unire di nuovo nell’ordine desiderato, oppure un tool dedicato [Riordina pagine PDF](/it/tools/reorder-pdf-pages) se disponibile.

Pianificare l’ordine dei file prima di unire fa risparmiare tempo ed evita di rifare il lavoro.

## Unire PDF su iPhone e Android

Puoi unire PDF su smartphone o tablet senza installare app. Apri la pagina FileFlip [Unisci PDF](/it/tools/merge-pdf) in Safari (iPhone/iPad) o Chrome (Android), poi:

1. Tocca **Carica** o **Aggiungi file** e scegli i PDF dal dispositivo o dal cloud (es. iCloud, Google Drive).
2. Riordina i file trascinandoli se l’interfaccia lo permette.
3. Tocca **Unisci** e attendi il risultato.
4. Scarica o condividi il PDF unito.

L’elaborazione avviene nel browser; per file grandi una connessione stabile aiuta. Se hai molti PDF o file molto grandi, unire da computer può essere più veloce.

## Unire PDF vs combinare pagine

Spesso “unisci PDF” e “combina pagine PDF” vengono usati allo stesso modo: mettere più PDF o pagine in un unico file. In pratica:

- **Unisci PDF** — Di solito significa prendere più *file* PDF e produrre un PDF che contiene tutte le loro pagine in un ordine scelto. È quello che fanno tool come quello di merge di FileFlip.
- **Combina pagine** — Può significare la stessa cosa di unire, o a volte inserire pagine specifiche da documenti diversi in un unico documento. Il risultato è comunque un PDF.

Quindi nell’uso quotidiano “unisci” e “combina” sono spesso intercambiabili. Conta poter aggiungere più PDF, impostare l’ordine e ottenere un unico file di output—ed è proprio quello che offre il tool Unisci PDF di FileFlip.

Sì. Il tool Unisci PDF di FileFlip è gratuito; non serve account né abbonamento. Potrebbero esserci limiti su dimensione file o numero di file per esecuzione.

L’unione in genere mantiene il contenuto com’è (stesso testo, immagini e risoluzione). Il tool combina le pagine senza ricodificare salvo indicazione contraria.

Sì. Puoi aggiungere tutti i PDF consentiti dal tool e unirli in un’unica volta. Controlla i limiti del tool per numero massimo di file o dimensione totale.

**I miei file vengono caricati su un server?**  
Quando il tool gira in locale, i tuoi PDF sono elaborati sul dispositivo e non inviati a un server. Vedi la pagina del tool per i dettagli.
