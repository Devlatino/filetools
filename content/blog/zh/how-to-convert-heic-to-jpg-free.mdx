如果你曾尝试将 iPhone 照片分享给使用 Windows 或 Android 的人，很可能遇到过 HEIC 问题：在 iPhone 上能正常打开，在其他设备上却显示为无法识别的格式。本指南说明如何免费将 HEIC 转为 JPG，无需下载应用或订阅。

## 什么是 HEIC，iPhone 为什么使用它？

HEIC 即高效图像容器格式。苹果从 iOS 11 起将其作为相机默认格式。原因很简单：在相同画质下，HEIC 文件体积约为 JPG 的一半，能在 iPhone 上存更多照片。

问题在于兼容性。HEIC 是苹果格式，现代 Mac 可原生打开，而 Windows 10/11 需从微软商店购买解码器才能查看；Android 则普遍不支持。多数社交媒体、网页表单和文档编辑器只认 JPG 或 PNG，不认 HEIC。

## 为什么需要把 HEIC 转为 JPG

常见场景包括：

- 通过**邮件或 WhatsApp** 把照片发给使用 Windows 或 Android 的人
- **上传到网站或表单**，且只接受 JPG/PNG
- 在 **Photoshop、Lightroom、GIMP** 等软件中编辑
- 在**社交媒体**上分享（不支持 HEIC 的平台）
- **冲印照片**或提交给打印服务
- **附在文档**（如简历、申请表）中

## 在 Windows 10/11 上把 HEIC 转为 JPG

**方式 1：使用“照片”应用（需安装解码器）**  
微软在应用商店提供 HEIF 图像扩展解码器。安装后可用“照片”打开并另存为 JPG（部分地区需付费）。

**方式 2：使用“画图”**  
在较新的 Windows 11 中，安装解码器后可在“画图”中打开 HEIC，然后“文件 → 另存为 → JPEG”。

**方式 3：使用 FileFlip（免费、免安装）**  
用 Chrome 或 Edge 打开 FileFlip 即可。

## 在 Mac 上把 HEIC 转为 JPG

在 macOS 上，HEIC 会默认用“预览”打开。转为 JPG：用“预览”打开 HEIC → 文件 → 导出 → 格式选 JPEG → 存储。若需批量转换，用 FileFlip 更省事：一次选多个文件，下载一个 ZIP 即可。

## 让 iPhone 直接拍成 JPG

若希望 iPhone 始终保存为 JPG：**设置 → 相机 → 格式** → 选择 **“兼容性最佳”** 而非“高效”。注意 JPG 会比 HEIC 占用更多空间。

## HEIC 与 JPG 对比

| 项目 | HEIC | JPG |
|---|---|---|
| 文件大小 | 更小（约一半） | 更大 |
| 画质 | 相当或更好 | 标准 |
| 兼容性 | 主要苹果设备 | 通用 |
| 编辑支持 | 有限 | 广泛 |
| 网页支持 | 否 | 是 |

**结论：** 在苹果设备上 HEIC 更省空间；要分享、兼容和上网用，JPG 更合适。需要分享时再转为 JPG，平时可保留 HEIC 以节省空间。
