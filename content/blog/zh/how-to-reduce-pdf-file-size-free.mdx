PDF 文件过大时，处处都会出问题：邮件附件被拒、上传表单有大小限制、通过 WhatsApp 分享时会被压缩。本指南说明如何免费缩小 PDF 文件大小，同时保持可读性。

## 为什么我的 PDF 这么大？

了解原因有助于选对方法。常见原因主要有三个：

**PDF 内嵌高分辨率图片**
从 Word、PowerPoint 或扫描件生成 PDF 时，图片往往以完整分辨率（300 DPI 或更高）嵌入。一份包含 10 张高分辨率照片的文档很容易超过 20MB。压缩这些内嵌图片是缩小体积最有效的方式。

**扫描件按图像保存**
如果纸质文档扫描后存成 PDF，每一页都是一张完整分辨率的“照片”。这类 PDF 可能非常大，有时一页就有 5–10MB。压缩会把图像质量降到更适合网页的级别。

**内嵌字体和资源**
PDF 会嵌入字体副本以保证在任何设备上正确显示。字体集很大或很生僻时，会明显增加体积。通常影响较小，但也值得注意。

## 其他缩小 PDF 的方式

若仅靠压缩仍不够，可以配合以下方式：

**先拆分再分别压缩**
用 [拆分 PDF](/zh/tools/split-pdf) 把大文档拆成几部分，分别压缩后再用 [合并 PDF](/zh/tools/merge-pdf) 合并，有时比一次性压缩整个文件效果更好。

**只保留需要的页面**
若只需分享部分页面，用 [提取 PDF 页面](/zh/tools/extract-pdf-pages) 抽出相关页。只分享 3 页而不是 30 页，是“减重”最直接的办法。

**转为 PDF/A 便于归档**
若需长期归档并保证兼容性，可用 [PDF 转 PDF/A](/zh/tools/pdf-to-pdfa) 转为 ISO 归档格式。

## 常见问题

**压缩会降低文字质量吗？**
不会。FileFlip 的压缩主要优化内嵌图像，不影响文字。压缩后的 PDF 中文字仍然清晰、可搜索、可复制。

**机密 PDF 在线压缩安全吗？**
使用 FileFlip 时是安全的。压缩在浏览器内用 JavaScript 完成，PDF 不会上传到任何服务器，适合合同、病历、财务报表等。

**压缩后仍然太大怎么办？**
可先用 [拆分 PDF](/zh/tools/split-pdf) 只提取需要的页面。若 PDF 内大量高分辨率图片，说明压缩已接近极限，此时需要在制作 PDF 前把原图以较低分辨率重新导出。

**能压缩带密码的 PDF 吗？**
先用 [解锁 PDF](/zh/tools/pdf-unlock) 去掉密码，再压缩已解锁的文件；如需可再用 [保护 PDF](/zh/tools/protect-pdf) 重新加密码。

**缩小 PDF 会影响数字签名吗？**
会。压缩会修改文件内容，通常会使数字签名失效。若 PDF 有法律效力的数字签名，请保留已签名原件，仅分享压缩版作参考。

**扫描生成的 PDF 怎么缩小？**
扫描版 PDF（每页即一张图）压缩效果很好。上传到 FileFlip 后，压缩会把图像 DPI 降到适合网页的水平，通常可缩小 50–70%。
