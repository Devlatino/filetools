# 如何免费合并 PDF 文件 — 在线合并 PDF

合并 PDF 是办公和日常中最常见的需求之一。把多份文件合并成一份 PDF 再发送，比发多个附件更省事、更整齐。本指南介绍如何免费合并 PDF —— 在线、在 Windows、Mac、iPhone 和 Android 上均可操作。

## 为什么要合并 PDF？

- **求职** — 将简历、求职信和证书合并成一份 PDF
- **发票与合同** — 将多页合并为一份文档便于签字
- **学习资料** — 将课程 PDF 按科目合并成一份
- **报告** — 将数据导出、图表和文字分析合并为一份文档
- **法律文件** — 将附件和参考资料与主文档合并
- **扫描件** — 扫描仪若每页生成一个 PDF，可合并为一个文件

## 如何用 FileFlip 免费合并 PDF

[FileFlip 的合并 PDF 工具](/zh/tools/merge-pdf) 在浏览器内将多个 PDF 合并为一个文档。无需上传到服务器、无需注册、无水印、完全免费。

### 第一步：打开合并 PDF
访问 [fileflip.org/tools/merge-pdf](/zh/tools/merge-pdf)。

### 第二步：上传 PDF 文件
点击上传或将 PDF 文件拖放到页面。可上传任意数量。

### 第三步：调整顺序
在上传列表中拖拽文件调整顺序，合并后的 PDF 将按此顺序排列。

### 第四步：合并并下载
点击「合并 PDF」后下载合并好的文件。几秒钟即可完成。

## 在 Windows 上免费合并 PDF

### 方法一 — FileFlip（浏览器，免安装）
最快的免费方式，适用于 Chrome、Edge 或 Firefox。

### 方法二 — Microsoft Word
1. 打开 Word → 插入 → 对象 → 文件中的文字
2. 选择要合并的 PDF
3. Word 会将其转为可编辑格式 — 再通过 文件 → 导出 → 创建 PDF

注意：复杂版式的 PDF 可能发生格式变化。

### 方法三 — Adobe Acrobat（付费）
Acrobat 有专门的「合并文件」功能，需订阅（约 19.99 美元/月）。FileFlip 可免费达到同样效果。

## 在 Mac 上免费合并 PDF

### 方法一 — 预览（系统自带，免费）
1. 在「预览」中打开第一个 PDF
2. 打开 显示 → 缩略图
3. 将其他 PDF 的页面拖入缩略图面板
4. 通过拖拽调整顺序
5. 文件 → 导出为 PDF 保存合并后的文档

适合在 Mac 上合并少量、内容简单的 PDF。

### 方法二 — FileFlip（浏览器，文件多时更快）
合并超过 3–4 个文件时，FileFlip 比在预览里拖拽更省时、更稳定。

## 在 iPhone 上免费合并 PDF

1. 打开 Safari 访问 [fileflip.org/tools/merge-pdf](/zh/tools/merge-pdf)
2. 点击上传，从「文件」应用中选择 PDF
3. 如需可调整顺序，再点击合并 PDF
4. 将合并后的文件下载到 iPhone

iOS 没有内置的 PDF 合并功能，FileFlip 是最简单的免费方案。

## 合并 PDF 小贴士

**注意页面方向** — 若有的 PDF 是纵向、有的是横向，合并后会出现混合方向，一般没问题，但发送前最好检查。

**合并后再压缩** — 合并后的 PDF 往往比预期大。合并完成后可用 [压缩 PDF](/zh/tools/compress-pdf) 减小体积，便于邮件或上传。

**仔细核对顺序** — 在 FileFlip 中可拖拽调整文件顺序。多部分文档尤其要确认顺序正确。

**带密码的 PDF** — 若任一源 PDF 有密码，请先用 [解锁 PDF](/zh/tools/pdf-unlock) 解除保护，再合并。

## 常见问题

**可以免费合并 PDF 且无水印吗？**  
可以。FileFlip 合并 PDF 完全免费，不会添加水印，输出干净、专业。

**合并数量有限制吗？**  
FileFlip 在浏览器中处理，没有服务器端限制。批次很大时，处理时间取决于设备内存。

**合并会损失质量吗？**  
不会。图片、文字、字体和版式都会完整保留。

**可以合并 PDF 和 Word 吗？**  
不能直接合并。先用 [Word 转 PDF](/zh/tools/word-to-pdf) 将 Word 转为 PDF，再合并两个 PDF。

**可以合并 PDF 和 JPG 吗？**  
先用 [JPG 转 PDF](/zh/tools/jpg-to-pdf) 将 JPG 转为 PDF，再用合并 PDF 合并。

**合并机密 PDF 安全吗？**  
安全。处理全部在本地浏览器完成，文件不会上传到任何服务器。

**合并后能调整页面顺序吗？**  
合并前可以调整整份文件的顺序。若要在单个 PDF 内调整页面，请用 [拆分 PDF](/zh/tools/split-pdf) 提取页面后再按顺序合并。

**为什么合并后的 PDF 很大？**  
每个源 PDF 都会完整加入。若原文件含高分辨率图片，合并文件会较大。合并后使用 [压缩 PDF](/zh/tools/compress-pdf) 可减小体积。
